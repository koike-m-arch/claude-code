# ブリリオ週次レポート作成スキル

## 目的

アルマードスプレッドシートの該当月レポートタブからデータを読み込み、各セクションのテキスト（全体サマリー・CPN別・CR別・記事検証）を先方提出用にまとめる。

## スプレッドシート情報

| 項目 | 値 |
|------|-----|
| レポートシート（月別タブ） | `1tHR-TuYIukF14f_Vljyh932yaL-_4xwp6MNkBZSwhTY` |
| タブ名の形式 | `2605~レポート`（YYMM~レポート） |
| 月別/週別データ | `【合算】月別` タブ |

---

## 実行手順

### Step 1: シート確認・データ読み込み

1. `get_spreadsheet_info` でシート一覧を取得し、該当月のレポートタブを特定
2. `read_sheet_values` で該当タブを読み込む（A1:AZ で全体を把握）
3. 以下を順番に確認する：
   - 月別進捗（OB・全体）
   - 週別進捗（OB・全体）
   - CPN構成（進捗マーク：〇△☓）
   - ①CPN数値進捗（配信費・CPC・LP遷移率・LPCVR・CV・CPA）
   - ②CR数値進捗（CPN別・CR別の数値）
   - 日別進捗（日ごとのCPA・LPCVR推移）

### Step 2: データを整理してユーザーに提示

読み込んだデータを以下の形式でまとめてユーザーに見せる：

- 今週 vs 先週 vs 先月のCPA比較表
- 日別CPA推移（特に変動が大きい日を強調）
- CPN別サマリー（好調・要観察・停止済みに分類）
- グレーアウト（配信停止）CPNの確認

### Step 3: ユーザーからメモを受け取る

各セクション（全体サマリー・CPN別・CR別・記事検証）のメモ・走り書きを受け取り：
- 誤字・脱字は自動修正
- ロジックの矛盾は厳しめに指摘し、修正案もセットで提示

### Step 4: 先方提出用テキストに仕上げる

メモが揃ったら各セクションを整えて出力する。

## レポート構成

1. **全体サマリー**（段落形式・数値なし）
2. **CPN別進捗**（事実・仮説・方針）
3. **CR別進捗**（コメント・仮説・方針）
4. **記事検証**（コメント・仮説・方針）

---

## 分析フレームワーク

### CPA構造の分解
```
CPA ≈ CPC ÷ (LP遷移率 × LPCVR)
```
CPAが悪化している場合、CPC・LP遷移率・LPCVRのどれが主因かを必ず特定する。

### CPN分析の観点
- グレーアウト（配信停止）CPNは分析対象外。方針では「停止済み」として記載
- 日別のCPA推移でイベント（GW・祝日等）の影響を確認する
- LP遷移率とLPCVRの両方が変動しているかを必ずチェック

### CR分析の3分類
1. **確立済み勝ちCR（◎）**：安定して獲得に貢献しているCR
2. **新たに勝ちになったCR（◎）**：今週・今月に勝ちとして確立されたCR
3. **CPNによっては獲得できるCR（〇）**：配信設定次第で機能するCR

### テキストCR分析の軸
- CTR・LP遷移率・LPCVRの3指標を比較する
- 「広くCTRを集めて記事で絞り込む設計」 vs 「見出しで高意欲層を最初から絞り込む設計」の違いを意識する

## セクション別 書き方ルール

### ①全体サマリー
- 事実・仮説・方針に**厳密に分けない**。段落形式で大枠を書く
- **細かい数値は入れない**（詳細は各セクションに任せる）
- 構成：先月比・先週比の評価 → CPA変動の主因 → 今後の方針
- GW・祝日・季節要因があれば必ず触れる

```
（例）
GW期間中（5/1〜5/5）は獲得が好調に推移しており、先月（4月）比でもCPAは改善傾向となっております。
一方、GW終了直後の5/6・5/7にかけてCPAが急騰しており、先週比では悪化している状況でございます。

CPA高騰の主因はLP遷移率・LPCVRの低下にあると推察しており、GW終了に伴いユーザーの購買意欲が
下がっている可能性があるものと考えております。そのため、一時的に各CPNの日予算を抑制しながら
今週末の配信を行ってまいります。
```

### ②CPN別進捗（事実→仮説→方針）

```
事実
・GW終了後の直近2日（5/6・5/7）でCPAが高騰しております。
・要因としては、CPCはほぼ横ばいだが、LP遷移率の微減に加えLPCVRが急落していることが主因でございます。
・CPN別では【102】・【096】・【100】が配信量上位だが、GW明けの影響を受けCPAが高騰傾向にございます。

仮説
・GW中は購買意欲の高い層が流入していたが、GW明けに購買モードが低下した層が中心となり
　LPCVRが低下したと推察。

方針
・現在は各CPNの日予算を抑制して配信をしております。
・また、好調CPN（【101】・【102】・【107】）への予算を優先集中させ、CPA安定化を図ってまいります。
```

### ③CR別進捗（コメント→仮説→方針）

```
コメント
・引き続き、既存勝ちCR（①〜③）は今週も◎評価で安定した獲得に継続貢献。
・今週新たに④が◎評価となり、勝ちCRの軸として確立されつつある。
・⑤⑥は〇評価で、CPNによっては獲得が好調に推移している状況。
・テキスト検証（【110】）では「〜」「〜」で初動から獲得ができており、良好な感触が得られている。

仮説
・テキスト検証が好初動を示している理由として、「60代」というターゲット年齢を見出しで明示していることが
　最も大きな要因と考えられる。
・CTRは低いものの、LP遷移率・LPCVRが既存勝ちCRの水準を大幅に上回っており、クリックした60代ユーザーの
　自分ごと化が強く起きていると推察。
・既存勝ちCRが「広くクリックを集めて記事で絞り込む」設計であるのに対し、検証テキストは「見出し時点で
　購買意欲の高い層のみを引き込む」設計であり、訴求軸として異なるアプローチができている可能性がある。

方針
・既存勝ちCR①〜④を軸にした配信を維持しながら、⑤⑥への配分を段階的に増やしてまいります。
・検証テキストはLPCVRが高いため、配信を継続しながら勝ちCRとして確立できるか見極めてまいります。
　→「60代×比較訴求」の訴求軸が有効と判断できた場合、類似テキストバリエーション（「50代が分かれ道」等）
　　にも横展開して検証範囲を広げていく。
```

### ④記事検証（コメント→仮説→方針）

```
コメント
・既存の再認識コンテンツ（一方的に情報を提示する形式）に対し、選択式再認識コンテンツ
　（ユーザーが選択しながら読み進める形式）の検証を実施いたしました。
・結果として、LPCVRが4.80%→6.10%（+1.30pp）、CVRが0.55%→0.80%（+0.25pp）と顕著な改善が確認できております。

仮説
・改善の主因として、「選択する」という能動的な行為がユーザーの自分ごと化を促進したことが考えられる。
　一方的に情報を受け取る形式と異なり、選択行動を通じてコンテンツへの関与度が高まり、LP到達時に
　購買意欲が高い状態を維持できていると推察。
・加えて、選択を経たユーザーは途中で離脱しにくく、LP到達時点で興味度の高い層が絞り込まれているため、
　LPCVRの底上げにつながっていると考えられる。

方針
・OBでのLPCVR・CVR改善が確認できたため、TBでも同コンテンツを実装して配信を開始してまいります。
・OB・TB両媒体での数値を比較しながら、さらなるコンテンツ改善の優先度判断に活用してまいります。
```

## スタイルルール（全体共通）

- **丁寧語**（です・ます・ております・でございます）で統一
- 「・」箇条書きで各点を簡潔に記載（1点1〜2文）
- 方針は「〜してまいります」で統一、詳細補足は「→」で続ける
- 仮説・推察には「〜と推察」「〜と考えられる」「〜可能性がある」を使う
- 全体サマリーのみ数値を省き大枠で書く。CPN別以降は数値を使って具体的に書く
